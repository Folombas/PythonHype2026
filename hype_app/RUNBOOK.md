# RUNBOOK · Как запустить FinPulse Hype после смены

> Уровень: «дядя Вася», сантехник. Один шаг = одна команда = что ты увидишь = что делать, если ошибка.
> Заранее ничего понимать не надо — просто повторяй команды по порядку.

## Шаг 0. Что это вообще такое (на пальцах)

Представь трубу с водой: новости «втекают» (ingest), фильтр считает статистику (analytics),
умник-пересказчик делает краткую выжимку (AI), кран наружу выдаёт данные (API),
а приборная панель показывает картинки (dashboard). Сейчас подключим эту трубу к твоему компьютеру.

## Шаг 1. Включи компьютер и проверь интернет

Открой браузер, зайди на любой сайт. Открылся? Интернет есть.
Нет — сначала почини интернет (это как закрыть кран перед пайкой).

## Шаг 2. Установи три инструмента (один раз в жизни)

Открой PowerShell (Пуск -> набери `powershell` -> Enter) и вводи по одной строке, после каждой жди окончания:

```powershell
winget install Git.Git
winget install Python.Python.3.12
winget install astral-sh.uv
```

Что увидишь: строки установки, потом «Successfully installed».

Если ошибка: перезапусти PowerShell «от имени администратора» и повтори.
Если winget не найден — обнови Windows или поставь Python с python.org (галочка «Add to PATH»!).

## Шаг 3. Закрой и снова открой PowerShell

Это чтобы он «увидел» новые инструменты. Проверь:

```powershell
git --version
python --version
uv --version
```

Что увидишь: три номера версий. Какая-то команда «не распознана» — вернись к шагу 2.

## Шаг 4. Скачай проект

```powershell
cd $HOME
git clone https://github.com/Folombas/PythonHype2026.git
cd PythonHype2026
git checkout hype-app
cd hype_app
```

Что увидишь: строки `Cloning into...`, `Switched to branch `hype-app``.

Если ошибка: проверь интернет и что ты в папке PythonHype2026 (команда `pwd` показывает, где ты).

## Шаг 5. Собери «трубу» (зависимости)

```powershell
uv sync
```

Что увидишь: много строк `Resolved` / `Prepared` / `Installed` — и в конце ничего страшного.
Это uv ставит библиотеки в изолированную песочницу `.venv`
(как отдельный щиток, чтобы не коротнуло весь дом).

Если ошибка: пришли текст ошибки; чаще всего помогает `uv sync --refresh`.

## Шаг 6. Залей новости (первый запуск)

```powershell
uv run hype ingest
uv run hype ls
```

Что увидишь: ingest скажет, сколько статей загружено; ls нарисует таблицу новостей (Rich-таблица).

Если ошибка: запусти `uv run hype --help` — он покажет точные команды и флаги твоей версии; следуй им.

## Шаг 7. Включи кран наружу (API)

```powershell
uv run hype serve
```

Эквивалент «вручную», если хочется видеть все флаги:

```powershell
uv run uvicorn hype.api.app:create_app --factory --port 8000
```

Что увидишь: `Uvicorn running on http://127.0.0.1:8000`.
Теперь открой в браузере http://127.0.0.1:8000/docs — интерактивная панель всех «кранов» (эндпоинтов).
Нажми `/health` -> `Try it out` -> `Execute` — увидишь `{"status":"ok"}`.

Остановить: в PowerShell нажми Ctrl+C.
Если ошибка «port already in use»: кто-то занял порт 8000 — используй `--port 8001`.

## Шаг 8. Включи приборную панель (dashboard)

В новом окне PowerShell (старое с API не закрывай):

```powershell
cd $HOME\PythonHype2026\hype_app
uv run streamlit run src/hype/dashboard.py
```

Что увидишь: браузер сам откроет http://localhost:8501 — графики и фильтры.
Если база ещё пустая — на кнопке в приложении есть заливка демо-данных.
Остановить: Ctrl+C.

## Шаг 9. Проверь, что всё здорово (тесты)

```powershell
uv run pytest -q
```

Что увидишь: строка вида `NN passed` — опрессовка трубы: все соединения держат.

Если ошибка: пришли вывод; не чини наугад.

## Шаг 10. Обновление и выключение

Обновить: `git pull`, затем `uv sync`.
Выключить всё: Ctrl+C в каждом окне, где что-то запущено; закрыть PowerShell.
Компьютер можно выключать — данные лежат в `data/hype.duckdb`.

## Если что-то пошло не так (таблица)

| Симптом | Причина | Лечение |
|---|---|---|
| «не распознано имя команды» | не перезапустил PowerShell / нет в PATH | шаг 3; переустанови с галочкой PATH |
| `uv sync` ругается на сеть | интернет/прокси | проверь интернет, повтори |
| port already in use | порт занят | `--port 8001` (API) или закрой старое окно |
| ModuleNotFoundError | не сделал `uv sync` / запустил без `uv run` | всегда запускай через `uv run ...` |
| браузер не открыл dashboard | не открылся сам | вручную: http://localhost:8501 |
| всё сломалось после правок | грязное состояние | `git status`, пришли вывод QA |

## Мини-словарь для дяди Васи

- **uv** — прораб, который ставит библиотеки в отдельную песочницу.
- **venv / .venv** — та самая песочница (изолированный щиток).
- **порт (8000/8501)** — номер двери, в которую стучится браузер.
- **API /docs** — панель с кранами и кнопками «проверить».
- **Ctrl+C** — аварийный вентиль «стоп».
