## Шаг 0. Включи компьютер и войди в систему
1. Нажми кнопку питания на системном блоке/ноутбуке.
2. Дождись рабочего стола (фон, значки).
3. Если просит пароль - введи свой обычный пароль от Windows.

✅ **Что увидишь:** рабочий стол, внизу панель «лупа».

## Шаг 1. Проверь интернет (как проверить воду перед пайкой)
1. Открой браузер (значок Chrome / Edge / Яндекс - лиса).
2. Вверху в адресной строке набери: `ya.ru` и нажми Enter.

✅ **Что увидишь:** открылась страница Яндекса - интернет есть.
❌ **Если не так:** нет интернета - сначала починь его (роутер/кабель), без него дальше никак.

## Шаг 2. Открой «синее окно» команд (PowerShell)
1. Нажми кнопку **«Пуск»** (внизу слева).
2. Просто начни печатать на клавиатуре: `powershell`.
3. В результатах нажми **«Запуск от имени администратора»**.
4. Если спросит «Разрешить?» - нажми **«Да»**.

✅ **Что увидишь:** синее/чёрное окно с мигающим курсором. Это «пульт управления».
💡 **Как вставлять команды:** скопировал текст (Ctrl+C) - в синем окне клик **правой кнопкой** (или Ctrl+V) и Enter.

## Шаг 3. Поставь три инструмента (один раз в жизни)
Вставляй по одной строке, после каждой жми Enter и жди, пока перестанет бегать текст:

```powershell
winget install Git.Git
winget install Python.Python.3.12
winget install astral-sh.uv
```

✅ **Что увидишь:** в конце каждой - что-то вроде «Successfully installed».
❌ **Если не так:**
- «winget не распознан» - обнови Windows или поставь Python вручную с python.org (галочка «Add to PATH»!).
- Просит админ-права - ты открыл PowerShell не от администратора; закрой и открой снова по Шагу 2.

## Шаг 4. Закрой синее окно и открой заново
Это обязательно: окно должно «увидеть» новые инструменты.
1. Закрой окно (крестик).
2. Открой снова как в Шаге 2.
3. Проверь три команды (по одной, Enter):

```powershell
git --version
python --version
uv --version
```

✅ **Что увидишь:** три строки с номерами версий (например `git version 2.4x`).
❌ **Если не так:** какая-то «не распознана» - вернись к Шагу 3 и переустанови этот инструмент.

## Шаг 5. Скачай проект (как получить чертёж трубы)

```powershell
cd $HOME
git clone https://github.com/Folombas/PythonHype2026.git
cd PythonHype2026
git checkout hype-app
cd hype_app
```

✅ **Что увидишь:** `Cloning into 'PythonHype2026'...`, потом `Switched to branch 'hype-app'`.
❌ **Если не так:**
- «already exists» - папка уже скачана; пропусти `git clone`, просто делай `cd PythonHype2026`.
- «not a git repository» - ты не в той папке; набери `pwd` (покажет где ты) и попробуй `cd` заново.

## Шаг 6. Собери «трубу» - поставь библиотеки

```powershell
uv sync
```

✅ **Что увидишь:** много строк `Resolved / Prepared / Installed ...`, в конце - ничего страшного.
❌ **Если не так:** красный текст про сеть - проверь интернет и повтори `uv sync`.

## Шаг 7. Залей новости и посмотри таблицу (первый пуск воды)

```powershell
uv run hype ingest
uv run hype ls
```

✅ **Что увидишь:** ingest напишет, сколько статей загружено; `ls` нарисует красивую таблицу новостей.
❌ **Если не так:** команда ругается на флаги - набери `uv run hype --help`, он покажет точные команды твоей версии.

## Шаг 8. Включи «кран наружу» (API) и открой панель кранов

```powershell
uv run uvicorn hype.api.app:create_app --factory --port 8000
```

✅ **Что увидишь:** строка `Uvicorn running on http://127.0.0.1:8000`. Окно «занято» - сервер работает.
1. Открой браузер, в адресной строке: `http://127.0.0.1:8000/docs`
2. Увидишь список «кранов» (эндпоинтов). Нажми `/health` - **«Try it out»** - **«Execute»**.

✅ **Что увидишь:** ответ `{"status":"ok",...}` - труба держит давление.
⭕ **Остановить сервер:** в синем окне нажми **Ctrl+C**.
❌ **Если не так:** `port already in use` - порт занят; запусти с `--port 8001`.

## Шаг 9. Включи приборную панель (dashboard) - во ВТОРОМ окне
1. Открой **ещё одно** синее окно (Пуск - powershell). Старое с сервером НЕ закрывай.
2. В новом окне:

```powershell
cd $HOME\PythonHype2026\hype_app
uv run streamlit run src/hype/dashboard.py
```

✅ **Что увидишь:** браузер сам откроет `http://localhost:8501` - графики, фильтры.
❌ **Если не так:** браузер не открылся сам - вручную открой `http://localhost:8501`.
⭕ **Остановить:** Ctrl+C в этом окне.

## Шаг 10. Опрессовка (тесты) - убедиться, что всё держит
В любом синем окне (где не бежит сервер):

```powershell
cd $HOME\PythonHype2026\hype_app
uv run pytest -q
```

✅ **Что увидишь:** строка `NN passed` (например `37 passed`). Это как опрессовка: соединения держат.
❌ **Если не так:** есть `failed` - скопируй вывод и пришли мастеру (QA). Сам ничего не чини наугад.

## Шаг 11. Выключение и обновление
- **Выключить всё:** Ctrl+C в каждом окне, где что-то бежит; закрыть окна; компьютеру можно отдыхать (данные лежат в `data/hype.duckdb`).
- **Обновить проект завтра:**

```powershell
cd $HOME\PythonHype2026
git pull
cd hype_app
uv sync
```

## 🚨 Таблица «если что-то пошло не так»

| Симптом | Причина | Лечение |
|---|---|---|
| «не распознано имя команды» | окно не перезапущено / не в PATH | Шаг 4; переустанови с галочкой PATH |
| `uv sync` ругается на сеть | интернет/прокси | проверь интернет, повтори |
| `port already in use` | порт занят | `--port 8001` или закрой старое окно |
| ModuleNotFoundError | не `uv sync` / запускаешь без `uv run` | всегда запускай `uv run ...` |
| браузер не открыл панель | не открылся сам | вручную `http://localhost:8501` |
| красный текст после правок | грязное состояние | `git status`, пришли вывод мастеру |

## 📚 Словарь для дяди Васи

- **uv** - прораб: ставит библиотеки в отдельную песочницу.
- **.venv** - песочница/отдельный щиток (изоляция).
- **порт 8000/8501** - номер двери, в которую стучится браузер.
- **API /docs** - панель кранов с кнопками «проверить».
- **Ctrl+C** - аварийный вентиль «стоп».
- **git clone/pull** - получить чертёж / обновить чертёж.

## 📋 Шпаргалка (распечатай и повесь у компа)

```powershell
cd $HOME\PythonHype2026\hype_app
uv sync                                                       # собрать
uv run hype ingest && uv run hype ls                          # залить + посмотреть
uv run uvicorn hype.api.app:create_app --factory --port 8000  # кран (docs в браузере)
uv run streamlit run src/hype/dashboard.py                    # панель (второе окно)
uv run pytest -q                                              # опрессовка
```

⭕ Стоп = Ctrl+C. Обновление = `git pull` + `uv sync`.

*Если застрял - не ломай: скопируй красный текст и пришли мастеру (QA). Труба починится.*
